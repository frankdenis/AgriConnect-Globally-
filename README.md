# AgriConnect — World's Largest Digital Agricultural Ecosystem

A comprehensive, zero-dependency, single-file agricultural marketplace platform connecting farmers, buyers, suppliers, processors, investors, transporters, and veterinarians across **25+ agricultural sectors**.

## 🌍 Features

- **25+ Agricultural Sectors** — Fish, Poultry, Livestock, Dairy, Piggery, Snail/Rabbit, Apiculture, Crops, Fruits, Spices, Cocoa/Palm, Forestry, Mushroom, Equipment, Greenhouse, Veterinary, Agrochemicals, Processing, Logistics, Drones, Solar, Investment, Training, Farm Land
- **40+ Product Listings** with real photography and realistic Nigerian market prices
- **Full Internationalization (i18n)** — Supports 21 languages: English, French, Spanish, Portuguese, Arabic, Chinese, Hindi, Swahili, Yoruba, Igbo, Hausa, German, Italian, Dutch, Japanese, Korean, Turkish, Indonesian, Vietnamese, Thai, Russian
- **RTL Support** for Arabic
- **Dashboard-wide Search** across all products and categories
- **Shopping Cart** with WhatsApp ordering integration
- **Business Account System** — Open registration for agri-businesses
- **Live Metrics** — Dynamic seller counts, listings, and ratings via localStorage
- **Mobile-first Responsive Design** with bottom navigation
- **PWA-ready** with manifest.json
- **SEO Optimized** with Schema.org structured data, Open Graph, Twitter Cards
- **Accessibility** — ARIA labels, focus-visible, semantic HTML
- **Zero Dependencies** — Pure HTML/CSS/JS, no frameworks, no build step

## 🚀 Quick Start

```bash
# Clone
git clone https://github.com/yourusername/agriconnect.git
cd agriconnect

# Serve locally
python3 -m http.server 8000
# Open http://localhost:8000
```

No build step required. Just open `index.html` in any browser or deploy to any static hosting.
